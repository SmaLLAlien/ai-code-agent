# Слой 4 — память, правила и Angular Material

**Результат слоя:** агент помнит договорённости команды во всех чатах и в длинных разговорах,
фиксирует решения проекта в самом проекте; стартер и платформа используют Angular Material в
фирменной теме; правила Angular и TypeScript доступны агенту.

Разница с историей (слой 3): история — это переписка одного чата (её видит только этот чат);
память — договорённости, которые подмешиваются в контекст **каждого** чата.

Объём пересмотрен с пользователем (2026-10-01): проектная память между чатами не нужна (1 чат =
1 проект); вместо неё — решения проекта в `docs/DECISIONS.md`.

---

## 4.1 Глобальная память команды
- Файл `<dataDir>/memory.md` (не в git, правится из UI). При первом запуске создаётся из шаблона
  `server/agent/memory.default.md` (в git) — договорённости по умолчанию: Angular Material, выжимка
  правил Angular и TypeScript со ссылками на полные файлы правил стартера.
- Подмешивание в каждый ран: extension `before_agent_start` → `sections['team_memory']` (ограничение
  размера, например 16 КБ; при превышении — обрезка с предупреждением в лог).
- API: `GET /api/memory` → `{ content }`, `PUT /api/memory` `{ content }` (валидация размера).

## 4.2 Тул `remember`
- Параметры `{ fact: string }`; дописывает строку `- <fact>` в раздел «Запомнено агентом» глобальной
  памяти (без дублей); результат — подтверждение. Карточка в ленте: «Запомнил: …».
- Правило в `server/agent/AGENTS.md`: когда вызывать (явное «запомни», устойчивые предпочтения команды),
  когда нет (детали конкретного проекта → `docs/DECISIONS.md`).

## 4.3 Решения проекта в `docs/DECISIONS.md`
- Правило в `server/agent/AGENTS.md` и скилах `writing-plans` / `executing-plans`: ключевые решения
  (стиль, структура, источники данных, отказ от функций) агент записывает в `docs/DECISIONS.md`
  проекта — кратко, с датой и причиной. В режиме plan запись этого файла тоже разрешена.

## 4.4 Сжатие длинных чатов
- Включить компакцию pi (`SettingsManager`, ключ `compaction`) с порогом под окно модели.
- События `compaction_start/end` → `CUSTOM { name: 'compaction' }` → в ленте пометка «Контекст сжат».

## 4.5 Правила TypeScript
- `.agents/rules/typescript-best-practices.md` — в стартере и в платформе; ссылки из `AGENTS.md`.

## 4.6 Angular Material
- **Стартер:** `ng add @angular/material`, тема M3 из фирменных цветов, типографика; правило в
  `AGENTS.md`: UI строить на компонентах Material, цвета — через токены темы. Новый тег `starter-v2`.
- **Платформа:** подключить Material с той же темой; на Material — только новый UI (панель памяти,
  диалог подтверждения вместо `window.confirm`). Остальные компоненты переводить постепенно.

## 4.7 UI памяти
- Кнопка «Память команды» в сайдбаре → диалог (Material) с редактором `memory.md` и «Сохранить».

## Проверка слоя
1. Тесты и сборки зелёные.
2. E2E: в чате A «запомни: …» → в новом чате B агент учитывает это без напоминания; правка памяти в UI
   сразу влияет на следующий ран.
3. Агент пишет `docs/DECISIONS.md` по ходу плана/реализации.
4. Новый воркспейс из `starter-v2` собирается, в нём Material и фирменная тема.
5. Обновить `memorybank.md`.
