# Слой 4 — память

**Результат слоя:** агент помнит важное между чатами и в длинных сессиях: решения по проекту и общие
предпочтения команды. Память видна и редактируема в UI.

Разница с историей (слой 3): история — это переписка одного чата; память — выжимка фактов, которая
подмешивается в контекст всегда.

**Перед началом:** сверь задачи с текущим кодом и `memorybank.md`.

---

## 4.1 Проектная память
- Файл `<workspace>/.agent/MEMORY.md` (коммитится вместе с проектом, команда видит решения).
- Подмешивание в контекст: `DefaultResourceLoader({ agentsFilesOverride: (cur) => ({ agentsFiles:
  [...cur.agentsFiles, { path, content }] }) })` (точную форму сверить с `.d.ts`), только если файл существует.

## 4.2 Глобальная память
- Файл `<dataDir>/memory.md` — общие предпочтения команды (стиль, запреты, частые требования).
- Подмешивание: extension `before_agent_start` → `sections['memory'] = <содержимое>` (с ограничением
  размера, например 8 КБ; при превышении — предупреждение в лог).

## 4.3 Тул `remember`
- Параметры `{ fact: string; scope: 'project' | 'global' }`; дописывает строку `- <fact>` в
  соответствующий файл (без дублей); результат — подтверждение.
- Правило в `server/agent/AGENTS.md`: когда вызывать (принятые решения, явные просьбы «запомни»,
  предпочтения), когда не вызывать (временные детали).
- Карточка действия в UI: «Запомнил: …».

## 4.4 Длинные сессии
- Включить компакцию pi (настройки `SettingsManager`, ключ `compaction`) с разумным порогом;
  события `compaction_start/end` → `CUSTOM { name: 'compaction' }` → в ленте пометка «контекст сжат».

## 4.5 UI памяти
- Панель «Память»: вкладки «Проект» / «Глобальная», просмотр и редактирование (textarea + сохранить).
- API: `GET/PUT /api/chats/:id/memory`, `GET/PUT /api/memory`.

## Проверка слоя
1. Тесты и сборки зелёные.
2. E2E: в чате A «запомни: основной цвет #0a7» → в новом чате B (глобальная память) агент использует цвет
   без напоминания; проектная память видна в `.agent/MEMORY.md` воркспейса.
3. Обновить `memorybank.md`.
