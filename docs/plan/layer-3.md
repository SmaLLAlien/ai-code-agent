# Слой 3 — история чатов

**Результат слоя:** чаты сохраняются, есть список чатов, можно вернуться в любой чат (в том числе после
рестарта сервера) и продолжить диалог с полной историей.

**Перед началом:** сверь задачи с текущим кодом и `memorybank.md`.

---

## 3.1 Хранилище метаданных
- `server/src/chats/chat.store.ts`: интерфейс `ChatStore` (`list`, `get`, `save`, `delete`) и реализация
  `JsonFileChatStore` — файл `<dataDir>/chats.json`, атомарная запись (временный файл + `rename`).
  Новый ключ конфига `data.dir` (`./data`, в `.gitignore`).
- Запись: `{ id, title, workspacePath, sessionFile, mode, todo, createdAt, updatedAt }` (без объекта сессии).
- Интерфейс нужен, чтобы позже заменить JSON на БД без правок остального кода.

## 3.2 Сохранение сессий pi
- В `createSession` вместо `SessionManager.inMemory(cwd)` → `SessionManager.create(cwd, <stateDir>/sessions/<chatId>)`;
  путь файла сессии — `session.sessionFile` → в метаданные.
- Восстановление: `SessionManager.open(sessionFile)` → `createAgentSession({ ..., sessionManager })`.
  Историю **не** присваивать через `session.agent.state.messages` (не сохраняется) — только через менеджер.
- Реестр: `get(id)` лениво поднимает сессию из стора, если её нет в памяти; неиспользуемые сессии
  выгружать (`dispose`) по таймауту простоя (например, 30 мин, ключ конфига).

## 3.3 API
- `GET /api/chats` → список (id, title, updatedAt), сортировка по `updatedAt` desc.
- `GET /api/chats/:id` → метаданные + `items: ChatItem[]`, собранные из `session.messages`
  (user / assistant text / tool calls с результатами). Конвертер — чистая функция + тесты.
- `PATCH /api/chats/:id` `{ title }`; `DELETE /api/chats/:id` (dispose сессии, удалить запись;
  воркспейс и файл сессии — удалять или оставить, решить и записать в memorybank).
- Заголовок чата — первые ~60 символов первого сообщения пользователя (ставится после первого рана).

## 3.4 UI
- Маршруты: `/` → редирект в новый чат или пустой экран «Новый чат»; `/chat/:id` → `ChatPage`.
- `ChatSidebar`: список чатов, «Новый чат», переименование, удаление (с подтверждением); активный выделен.
- `AgentSessionService.load(id)`: `GET /api/chats/:id` → `items`, `mode`, `todo`; `HttpAgent` с тем же
  `threadId`.
- На мобильной ширине сайдбар выдвижной.
